# Final addressing plan

Generated by `make deliverables` from
[inventories/common/group_vars/all.yml](../inventories/common/group_vars/all.yml),
the plan both sites share. All LAN interfaces are `/24`; the default
gateway of every VM is its OPNsense LAN address; the VIP is never assigned
statically (Keepalived moves it).

| Component | Site A | Site B |
|---|---|---|
| LAN subnet | `10.0.2.0/24` | `10.15.15.0/24` |
| OPNsense LAN (gateway, DNS) | `10.0.2.1` | `10.15.15.1` |
| OPNsense WAN | `192.168.100.11/24` | `192.168.100.12/24` |
| WAN upstream gateway | `192.168.100.1` | `192.168.100.2` (two computers) / `192.168.100.1` (one computer) |
| VIP (Keepalived, VRRP id) | `10.0.2.100` (id 51) | `10.15.15.100` (id 52) |
| HAProxy 1 — MASTER | `10.0.2.5` | `10.15.15.10` |
| HAProxy 2 — BACKUP | `10.0.2.6` | `10.15.15.11` |
| Web server (Nginx) | `10.0.2.7` | `10.15.15.7` |
| Database (MySQL) | `10.0.2.8` | `10.15.15.8` |
| Hypervisor (management only) | `10.0.2.254` | `10.15.15.254` |

## Flows

| Flow | Path | Ports |
|---|---|---|
| Public web | client → OPNsense WAN (destination NAT) → VIP → HAProxy → Nginx → MySQL | TCP 80, 443 |
| Inter-site | LAN → OPNsense → IPsec ESP tunnel → peer OPNsense → peer LAN (no NAT) | WAN: UDP 500, UDP 4500, ESP |
| Management | hypervisor `.254` → VMs (SSH), OPNsense GUI on LAN only | TCP 22, 443 |
